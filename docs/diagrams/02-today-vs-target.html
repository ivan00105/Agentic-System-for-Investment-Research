How to read it

  • Agents run three ways: B = one agent with every tool; C = a coordinator and three analysts (fundamentals, filings and events, market and valuation); D = C plus a critic. Discover uses them for each pick. Diagrams 4 and 5 open this box up.
  • Tools are plain Python. The LLM only picks a tool and fills in its arguments. Diagram 6 lists each tool.
  • Outlook is the one new part. No LLM writes its numbers: they are statistical forecasts, each shown with its track record (REFERENCE §6).
  • Evaluation calls the agents directly (not through the web app) and also runs A, the old fixed pipeline with no AI, as the control. The web app reads saved runs from the trace files for History.
