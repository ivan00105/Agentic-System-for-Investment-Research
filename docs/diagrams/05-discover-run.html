One Discover run

What Find companies does with criteria such as "large US tech, operating margin above 25%, reasonable valuation". It shows its reading of your words first, then walks the ranking until it has k good picks, runs out of research runs, or runs out of candidates.

Scroll the diagram sideways to see all of it.

How to read it

  • Screener spec: one LLM role with no tools writes the filters, the ranking rule, k and each vague term with a definition and 2–3 readings. You pick a reading (or type your own); a term you leave is marked "assumed". If you changed any, the screener redoes the spec with your answers. Professional level can edit the spec as JSON instead.
  • Screen universe is the screen tool run by the host over a declared list (sp500 by default, sp500_tech, sec_all or your own tickers), on SEC frames. Unknown never passes. Discover always uses today's data, so it takes no cutoff.
  • Passes check? repeats every filter on the latest 10-K and every price check (P/E, P/S, market cap…) on the latest close. No model; every line cites its record. A rejection here doesn't use up a run.
  • Research run is the run from diagram 4, one per candidate, with its own trace, filed under the Discover run in History. The web app uses condition B for these; the CLI takes --condition. A run that fails or ends with no claims is not a pick, but it still counts as a run.
  • Stop? k comes from the question, else 3. Research runs are capped at k + 3 (DISCOVER_MAX_REPLACEMENTS). Fewer than k picks is fine: the shortlist says why.
