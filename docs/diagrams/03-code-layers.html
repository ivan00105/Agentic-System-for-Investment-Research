How to read it

  • Read top to bottom: a request enters at the web app (or the CLI) and goes down. Nothing lower may import anything higher.
  • Agents is the focus: the LLM loop lives here. It talks to the LLM (through model_access.py) and gets every piece of data through a tool.
  • Outlook (dashed) is Phase 6: its maths goes in finance/, its tools in tools/, and the assembly and live log in outlook/.
  • Baseline A is the first version of the app, kept unchanged so the evaluation has a no-AI control.
